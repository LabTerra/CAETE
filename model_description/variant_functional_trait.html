Variant Functional Trait

CAETÊ features 19 variable functional traits (Descriptions, values, and units of the constant parameters k1-k22 and allometric constants in CAETÊ.), which define the vegetation’s functional identity. All trait ranges are derived from databases consistent with the observed values (e.g. TRY, Dryad).
